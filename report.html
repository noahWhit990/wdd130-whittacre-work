Final Project Report

Client Report

For my site, I decided to use foresty colors to fit the theme of a national park website. The logo I used was also created with this in mind. My lead developer did do a good job but the website doesn't seem to be fully complete. We mostly communicated by e-mail, but if there was something I'd do differently, I would have better contact with him.

https://jimmyghoyal-spec.github.io/wdd130-whittacre/

Lead Developer Report

As the lead developer, I contacted my junior devs occasionally by e-mail, but for the most part I put in the README and issues in github the pages that the junior devs would work on. There didn't seem to be any issues with communication; I was able to talk to the junior devs to get what we needed done done.

Junior Developer Report

My tasks as a junior developer went well as well. The lead devs were clear in what I needed to do, and I received the site plan for both, and was able to get it done in a timely manner. I was able to complete what I was assigned for each site.

General Experience and Reflections

I think the most challenging part of this project was probably just communicating between client and lead devs and junior devs, etc. But overall the project went really well. I enjoyed being able to bring someone's website to life and see it all come together. I think the only thing I would do differently is be better at communicating between all the different roles so the website could be accomplished more smoothly. I do feel more confident, if I improve communication between the parties I think I would be able to accomplish making a website for a client or lead dev.
